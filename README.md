# AI Web3 Task Assistant

A simple AI-style Web3 assistant that helps users generate daily Web3 and airdrop tasks.

## Features
- Daily Web3 task suggestions
- Airdrop guidance simulation
- Simple AI-like interaction

## Tech Stack
- HTML
- JavaScript

## OpenGradient Integration (Planned)
This project is designed to integrate with OpenGradient SDK for verifiable AI agent execution and on-chain inference in the future.
